## The DevOps Journey: From Manual to Automated

DevOps fundamentally transformed software development by breaking down silos and introducing automated pipelines the foundation of modern delivery.
{: .highlight-box}

### DevOps V1 Achievements:

- **CI/CD Pipelines** - Jenkins, GitLab CI, GitHub Actions, Bitbucket Pipelines - made everything automated
- **GitOps and Infrastructure as Code** - Terraform, Ansible, Helm - made everything redeployable
- **Containerization** - Docker, Kubernetes - avoiding it works on my machine
- **Monitoring & Alerting** - Prometheus, Grafana, Loki, Jaeger, ELK stack - see everything

**But DevOps V1 has limitations:** Brittle scripts, manual intervention still needed, reactive problem-solving, and limited adaptability.

> V1 scaled automation. It didn't scale *decisions*.
